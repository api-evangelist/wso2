WSO2 Identity Server 7.3.0 introduces capabilities for securing AI agents through delegated access mechanisms, enabling verifiable credential issuance for digital wallets, and expanding B2B identity features for multi-tenant SaaS platforms. The release allows ambient agents to operate continuously in the background while maintaining user control through backchannel authentication notifications. Additionally, new Vue.js and Nuxt.js SDKs provide framework-native components, and app-native authentication is extended to support SAML identity providers and device code flows.
